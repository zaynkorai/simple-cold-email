# Security Policy

## Supported Versions

We provide security patches and updates for the following versions of `simple-cold-email`:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `simple-cold-email`, please **do not open a public issue**. Instead, follow responsible disclosure practices:

1. **Email**: Send vulnerability details to `security@example.com` (or create a private GitHub Security Advisory).
2. **Details to include**:
   - Type of vulnerability (e.g. CSRF, session hijack, injection, sensitive data exposure)
   - Step-by-step instructions to reproduce the issue
   - Proof of concept code or HTTP request payloads
   - Potential impact and affected components
3. **Response timeline**:
   - Initial acknowledgement: within 48 hours
   - Vulnerability assessment and patch development: within 7 business days
   - Release and security advisory publication: upon validation of the patch

Thank you for helping keep this project and our users secure.
